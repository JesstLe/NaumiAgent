# Web2 归档 404 修复（2026-09-11）

## 原因与处理

Web2 调用 `POST /api/v1/sessions/{id}/archive`。检查时 8765 服务的
OpenAPI 不包含该路由，虽然当前源码已实现；原进程 PID 71424 启动于
12:49，未加载后续接口代码。因此这是运行中后端与源码不同步造成的路由 404。
修复期间后端被重新启动为 PID 92296（13:28），复查确认归档路由已加载。

共享 API 客户端将归档接口缺失与会话不存在分别提示：前者要求更新并重启
后端，后者要求刷新会话列表。409 执行中冲突保留服务端中文原因；失败不重试，
不把 404 当作归档成功。Web2 继续使用共享控制器移除列表项并清空当前选择。

## 消息终态操作与分支编辑（2026-09-12）

- 助手回复底部的复制、重新生成、点赞和点踩只在对应 Run 进入完成、失败、取消或阻塞等真实终态后显示。流式正文已经出现但用户轮仍为 pending、当前运行用户仍匹配，或持久 Run 仍为 running 时，操作区保持隐藏；没有 Run 记录的旧历史消息继续可操作。
- 用户消息复用现有图标按钮增加“编辑消息”。编辑态直接在原消息气泡内展开，可取消、Escape 退出、发送修改，或使用 Ctrl/Command+Enter 提交；会话切换和执行锁会清理或禁用编辑态。
- 编辑提交通过共享控制器携带 `edit_message_id`。后端在引擎运行锁内截断该用户消息及其后的旧会话分支，保存后重新加载会话，再以修改后的内容启动新 Run；普通聊天和 Web 支持的斜杠命令共用这套语义。刷新后只恢复新分支，不会重新出现旧问答。
- 后端拒绝空编辑、非用户消息、不存在的消息以及同会话仍在运行的编辑请求。旧 Run 继续保留为审计记录；前端只把请求摘要仍能匹配当前用户消息的旧 Run 关联到对话，避免被截断的记录错绑到其他消息。

验证覆盖 API 非流式和 SSE 流式截断、错误路径、活动运行冲突、共享控制器分支替换、Run 重新关联、Web2 编辑与刷新恢复、操作区运行中隐藏和终态显示。前端生产构建通过；真实服务验收结果随本次交付继续记录。

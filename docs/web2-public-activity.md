# Web2 具体执行摘要（2026-09-11）

## 问题

原执行过程仅有两句固定文案。TOOL_START 的公开传输丢弃所有参数，且页面
没有保留上下文压缩和任务快照事件，无法说明具体操作。历史回放还会优先展示
analysis.detail，不适合作为公开摘要来源。

## 实现

- 新增公共动作摘要构建器，只读取工具名称及有限的路径、命令、目标字段。
  不读取模型思考内容，不展示编辑正文、浏览器脚本或完整参数 JSON；敏感值脱敏，
  访问地址省略凭证、查询和片段，摘要有长度上限。
- 工具启动附带 activity_summary；持久化使用 metadata.public_action，结束事件
  保留原动作。引擎与 HTTP 两条记录路径复用相同生成规则。
- 任务快照与上下文压缩转换为公开进度行并持久化；压缩统计使用消息条数，
  不误标为 token 数。任务仅显示实际任务状态，未知操作保留名称。
- Web2 展示本次请求与工作目录、操作摘要与执行状态、上一步结果状态以及
  任务和压缩进展。历史记录从操作证据恢复，不读取 analysis.detail。
- 不收集 thinking_delta，避免无可见信息的高频事件挤掉实际工具记录。

## 验证与边界

语义上的“问题已修复”“布局正确”须由具体工具证据和最终答复给出；
本摘要不会因工具返回 success 就宣称产品验收通过。历史数据没有保存压缩／任务
事件时无法补造；尚未产生具体操作时，只展示本次任务与工作目录。

  旧记录回放、敏感字段过滤测试。旧后端的任务／压缩原始事件也支持回退生成摘要。

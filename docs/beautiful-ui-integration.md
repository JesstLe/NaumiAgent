# Beautiful UI 接入记录

来源：https://www.beautifului.dev/ ，2026-09-11 实查 21 类组件；源码入口为 `/r/<组件名>.json`，MIT，Copyright (c) 2026 Shane Levine。

## 布局决策

保留 Codex 的导航和面板层级。组件进入既有对话、摘要和内容区域；不新建左侧功能标签。公共数据转换放在 `frontend/shared`，展示在 `frontend/web2/src/beautiful`。注册表是带默认演示数据的源码，不是可直接接业务的包：移除样例、定时模拟完成和默认“接受成功”，绑定真实数据后才计为接入。
